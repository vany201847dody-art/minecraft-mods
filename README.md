# Мои самописные моды для Minecraft

Мои личные моды для **Minecraft 1.16.5** (Fabric). Всё, что здесь лежит — мои самописы.

Папка `mods/` — готовые собранные `.jar` для установки в `<папка игры>/mods/`.
Отдельные репозитории с исходниками:
- https://github.com/vany201847dody-art/optiforge
- https://github.com/vany201847dody-art/optirec
- https://github.com/vany201847dody-art/kotlovan

## Список моих самописов
| Мод | Что делает | jar в этой репе |
|-----|-----------|-----------------|
| **OptiForge** | Оптимизатор FPS, авто-подбор настроек под железо и моды | `mods/optiforge-1.0.jar` |
| **OptiRec** | Запись экрана с GUI/чатом через FFmpeg | `mods/optirec-1.0.jar` |
| **Kotlovan** | Чит-мод (Nuker, Fly, KillAura...) + ClickGUI | `mods/kotlovan-2.0.jar` |
| **ChatLogger** | Логгер чата | `mods/chatlogger-fabric-1.16.5-1.0.0.jar` |
| **Friends** | Система друзей | `mods/friends-fabric-1.16.5-1.0.0.jar` |
| **MusicPlayer** | Музыкальный плеер | `mods/musicplayer-fabric-1.16.5-1.0.1.jar` |

## Установка любого мода
1. Зайди в репозиторий, открой папку `mods/`, скачай нужный `.jar`.
2. Положи его в папку `mods/` своей игры (Minecraft 1.16.5 + Fabric Loader).
3. Перезапусти игру.

## Каким модам нужен Fabric API
Некоторые моды используют **Fabric API** и без него **не запустятся** (игра может вылететь или мод просто не загрузится). Поэтому для них сначала положи **Fabric API** в папку `mods/`.

| Мод | Нужен Fabric API? |
|-----|-------------------|
| **OptiForge** | ✅ Да |
| **OptiRec** | ✅ Да |
| **Kotlovan** | ✅ Да |
| **ChatLogger** | ✅ Да |
| **Friends** | ✅ Да |
| **MusicPlayer** | ✅ Да |

**Все мои моды требуют Fabric API.**

### ⚠️ Важно про версию Fabric API
- Для **Minecraft 1.16.5** нужна версия **`0.42.0+1.16`**.
- Fabric API для других версий (например `0.77.0+1.19.2`) **не подходит** под 1.16.5 и сломает игру — не ставь его.
- Скачать: https://modrinth.com/mod/fabric-api или https://www.curseforge.com/minecraft/mc-mods/fabric-api (выбери версию 1.16.5)

## Что ещё нужно для нормальной работы (без лагов)
- **Sodium** — сильно ускоряет рендер (главный буст FPS).
- **Lithium** — оптимизация игровой логики.
- **Phosphor** — оптимизация освещения.
- Мой мод **OptiForge** сам выставляет настройки (дальность, частицы, графика) под твоё железо.
- Для слабого ПК: рендер-дистанция 6–8 чанков, частицы «Минимум», графика «Быстрая».
