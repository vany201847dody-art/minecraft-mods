# Мои моды для Minecraft

Привет! Это мои собственные моды для **Minecraft 1.16.5** (на Fabric). Собирал сам, делюсь.

В папке **`mods/`** лежат готовые файлы — просто скачай и установи, как написано ниже.

---

## Мои моды
| Мод | Зачем нужен | Файл |
|-----|-------------|------|
| **OptiForge** | Чтобы игра работала быстрее и не лагала | `mods/optiforge-1.0.jar` |
| **OptiRec** | Запись видео с экрана игры (с чатом и меню) | `mods/optirec-1.0.jar` |
| **Kotlovan** | Чит-мод: полёт, ускорение, автобоец и другое | `mods/kotlovan-2.0.jar` |
| **ChatLogger** | Записывает чат в файл | `mods/chatlogger-fabric-1.16.5-1.0.0.jar` |
| **Friends** | Список друзей | `mods/friends-fabric-1.16.5-1.0.0.jar` |
| **MusicPlayer** | Проигрывание музыки в игре | `mods/musicplayer-fabric-1.16.5-1.0.1.jar` |

---

## Как установить
1. Открой папку **`mods/`** выше и скачай файл мода (`.jar`).
2. Зайди в папку игры и открой папку **`mods`**.
3. Перетащи туда скачанный файл.
4. Запусти игру.

---

## Тоже нужно поставить (без этого не заработает!)
Моим модам нужна специальная программа-заглушка **Fabric API**. Без неё они **не включатся**.

- Скачай **Fabric API** версии для **1.16.5** (она называется `0.42.0+1.16`).
- Положи её файл в папку **`mods`** так же, как и моды.

⚠️ **Важно:** бери именно версию для 1.16.5! Если поставить Fabric API от другой версии (например для 1.19.2) — игра сломается и не запустится.

Где взять: сайты Modrinth или CurseForge → поиск «Fabric API» → выбрать версию 1.16.5.

---

## Как сделать, чтобы не лагало (советы)
- Поставь ещё моды **Sodium** и **Lithium** — они сильно ускоряют игру.
- У меня в OptiForge есть автонастройка: он сам подбирает дальность прорисовки и частицы под твой компьютер.
- Если совсем слабый ПК: в настройках игры уменьши дальность прорисовки до 6–8 чанков, частицы поставь «Минимум», графику — «Быстрая».
